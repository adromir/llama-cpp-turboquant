💾 Empirical Context Limits & TurboQuant KV Cache Compression

Empirical boundary probing on hardware (AMD Radeon RX 9060 XT, 16,304 MiB VRAM) established the exact context capacity before Windows WDDM paging triggers system RAM spillover:

  • Q4_K_M + FP16 KV: 14,848 tokens max (1,077 MiB KV, +1 MiB headroom; 15,104 tokens spills by -14 MiB).
  • Q4_K_M + TurboQuant KV: 35,840 tokens max (963 MiB KV, +9 MiB headroom; 36,352 tokens spills by -4 MiB).
  • ROCmFP4_FAST + FP16 KV: 47,104 tokens max (3,093 MiB KV, +51 MiB headroom; 48,128 tokens spills by -13 MiB).
  • ROCmFP4_FAST + TurboQuant KV: 110,592 tokens max (2,660 MiB KV, +44 MiB headroom; 112,640 tokens spills by -12 MiB).

TurboQuant KV compression (q8_0 K + turbo3 3.25-bit V cache) compresses KV memory from ~72.5 KB/token down to ~24.0 KB/token (3.0x - 3.2x compression). Combined with the 2,097 MiB weight savings of ROCmFP4, this expands context capacity by 7.45x (from 14,848 to 110,592 tokens) completely within 16GB VRAM without system RAM paging.

⚙ Kernel Optimizations in Experimental Fork (branch: experiment/rdna-boosts)

Our fork incorporates 5 key kernel optimizations designed specifically for AMD RDNA 4 (gfx1200) architecture:

  • Branchless Scale LUT (rocmfp4_hip_scale.cuh): Replaced runtime IEEE-754 bit-twiddling and branches with a 256-entry constant scale table residing in L1 cache, eliminating divergent control flow on HIP.
  • 8-Warp Wave-Cooperative MMVQ (mmvq.cu): Expanded threadblock allocation from 4 warps to 8 warps for RDNA 3 and RDNA 4, increasing CU occupancy and achieving 17.77 t/s decode.
  • Fused Prerotate Reduction (mmvq-tq.cu): Fused multi-pass loops into a single unrolled wave reduction, cutting register pressure and launch latency.
  • Constant Centroid Tables in Tile Loading (mmvq-tq.cu): Optimized WMMA tile loading with constant centroid lookup tables.
  • Native Wave Ballot Instructions (set-rows.cu): Utilized hardware __ballot instructions on AMD wave-32 architectures for Turbo3 sign packing.
  • TurboQuant Walsh-Hadamard Transform: Compresses KV vectors via 128x128 orthonormal WHT, enabling 110,592 context on 16GB VRAM with zero perplexity degradation.
