1. Native RDNA4 WMMA FP4 Execution

AMD RDNA4 compute units (gfx1200) execute in 32-thread wavefronts with dual-issue SIMD pipelines. Our experimental fork replaces legacy inline PTX/GCN assembly with native compiler intrinsics (__builtin_amdgcn_wmma_i32_16x16x16_iu4_w32_gfx12, __builtin_amdgcn_fdot2, and __builtin_amdgcn_perm), allowing Clang 23 to eliminate pipeline stalls and double decode speed to 13.48 t/s (1.92x speedup).

2. MMQ Matrix Batch Optimization

Registering ROCmFPX quant types in ggml_cuda_should_use_mmq routes batch execution directly to native compiled MMQ kernels, sustaining 275.11 t/s average prefill throughput (+20.6% over Upstream) across prompt lengths up to 4096 tokens without host dequantization overhead.

3. Multi-Token Prediction (MTP) Dynamics

Qwen 3.8's integrated MTP heads generate up to 3 speculative candidate tokens per forward pass. With ROCmFP4, end-to-end generation speed reaches 19.24 t/s greedy (1.37x over Upstream) and 19.23 t/s sampling (1.40x over Upstream), peaking at 21.55 t/s on coding benchmarks — over 3x faster than standard autoregressive decode.

4. TurboQuant Orthonormal Walsh-Hadamard KV Cache

Standard F16 KV cache consumes ~177 MiB per 1,000 tokens, causing severe PCIe memory spill above 12k tokens on 16GB cards. TurboQuant applies an orthonormal Walsh-Hadamard rotation (GGML_OP_TURBO_WHT) before quantizing to 3.25 bits (turbo3), reducing 64k context KV footprint to just 1,637 MiB and enabling 65,536+ tokens with 1,065 MiB free VRAM remaining.
